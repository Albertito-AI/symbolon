# Governance

Albert Tan Sin Hon (`Albertito-AI`) owns the project and is its initial maintainer.
Contributors propose changes through issues and pull requests. The maintainer
decides scope and releases and records reasons for material design decisions in
`docs/decisions.md`.

The first release is an experimental reference implementation. There is no
foundation, verifier accreditation body, insurer relationship or dispute
institution represented by this repository. Broader participation and neutral
governance are objectives to develop through evidence and actual agreements.

Incompatible contract or evidence semantics require a new version, migration
notes and examples. Preserve released specifications and add versions alongside
them. Public security disclosures should follow `SECURITY.md`.

Repository settings such as protected branches, independent approvals and private
vulnerability reporting must be verified before they are described as enabled.
